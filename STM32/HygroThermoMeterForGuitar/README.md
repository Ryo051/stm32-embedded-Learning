# ギターのための湿度計温度計

## 1.概要
このプロジェクトでは湿度計温度計を作成する。のちにギター用のその他の機能追加（チューナー）もできるものを検討していく。

## 2.使用機器Thermometer
-**マイコンボード**
	- STMicroelectronics NUCLEO-G070RB

-**センサー**
	- DHT11 (温度湿度計)
-**出力機器**
	- 0,96 I2C OLED-Display
-**その他**
	- ブレッドボード
